# Email Automator UI

Public GitHub Pages frontend for the email automator.

## Features

- password-backed session check through backend
- recruiter/company form
- template picker
- optional custom subject
- template preview
- request submission to backend API

## Setup

1. Edit `docs/config.js`
2. Set `window.APP_CONFIG.apiBaseUrl`
3. Deploy `docs/` to GitHub Pages

## Notes

- This repo contains no secrets.
- Password validation and workflow dispatch happen in the backend repo.
